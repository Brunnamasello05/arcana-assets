ARCANA — BIBLIOTECA SONORA (OTIMIZADA)

Pasta "audio" com 8 arquivos MP3 para uso no mixer de Imersão.
Todos os arquivos foram convertidos para uso web, preservando a duração original.
Para evitar áudio interrompido durante a leitura, configurar reprodução com loop no aplicativo.

ATENÇÃO
- Mantenha os créditos da faixa 'floresta.mp3' acessíveis no Arcana (por exemplo, em 'Créditos sonoros').
- A gravação 'caixinha-musical' foi licenciada CC0 na página Freesound, porém há um comentário relatando
  uma reivindicação no YouTube. Se desejar evitar esse risco adicional, deixe-a fora do app.
- O ZIP não contém código alterado do Arcana.
- Se publicar no GitHub, use uma pasta 'audio' dentro do repositório arcana-assets.
- As faixas foram otimizadas; não foram feitos testes auditivos manuais em cada transição de loop.
